AI Prompts

Edit live prompts by section. Saved values are applied through public_config.ai_prompts without redeploying the app.

How It Works
SERVER
The save button writes prompts to the ai_prompts map in PocketBase public_config.
APP
Flutter reads this map before each related AI call; empty prompts fall back to safe code defaults.
DEFAULT
Editors show the current code defaults first; server overrides are marked with a badge.
